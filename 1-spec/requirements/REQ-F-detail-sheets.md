# REQ-F-detail-sheets: Tappable Detail Sheets for Cosmic Triad

**Type**: Functional
**Status**: Draft
**Priority**: Must-have
**Source story**: [US-view-sun-sign-detail](../user-stories/US-view-sun-sign-detail.md), [US-view-year-animal-detail](../user-stories/US-view-year-animal-detail.md), [US-view-element-detail](../user-stories/US-view-element-detail.md)

## Description

Each of the three Atlas tiles (sun sign, year animal, dominant element) opens a detail sheet with extended information and related data from the same astrological system.

## Acceptance Criteria

- [ ] Sun sign sheet: hero sign + moon sign row + ascendant row, each with description
- [ ] Year animal sheet: hero animal + day master + month pillar + hour pillar with element badges
- [ ] Element sheet: hero dominant element + all 5 element bars (sorted) + weakest element advice
- [ ] All sheets dismiss on swipe-down
