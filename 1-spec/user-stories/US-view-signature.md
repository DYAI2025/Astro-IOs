# US-view-signature: View My Personal Signature

**As a** end user, **I want** to see my personal dynamic signature on the Signatur tab, **so that** I intuitively understand my Fusion profile as a living visual form instead of numbers and tables.

**Status**: Draft
**Priority**: Must-have
**Source stakeholder**: [STK-end-user](../stakeholders.md)
**Related goal**: [GOAL-dynamic-signature](../goals/GOAL-dynamic-signature.md)

## Acceptance Criteria

- Given I have a Fusion profile, when I open the Signatur tab, then I see an animated visual signature unique to my natal data
- Given today is a Pulse day (H < 0.50), then the signature shows symmetric concentric rings with calm motion
- Given today is a Trace day (H ≥ 0.50), then the signature shows Lissajous crossing curves with micro-vibrations
- Given I complete a quiz, when I return to the Signatur tab, then the base shape has subtly shifted to reflect the contribution
- Given a geomagnetic storm is active (Kp ≥ 5), then the signature intensity visibly increases
- Given another user has different birth data, then their signature looks recognizably different from mine
