# US-view-element-detail: View Dominant Element Detail

**As a** end user, **I want** to tap on my dominant element tile and see all five element proportions, **so that** I understand my Wu-Xing balance and what it means.

**Status**: Approved
**Priority**: Must-have
**Source stakeholder**: [STK-end-user](../stakeholders.md)
**Related goal**: [GOAL-fusion-reading](../goals/GOAL-fusion-reading.md)

## Acceptance Criteria

- Given I am on the Atlas tab, when I tap the element tile, then a detail sheet opens
- Given the detail sheet is open, then I see dominant element hero, all 5 element bars (sorted by strength), and weakest element with growth advice
- Given my dominant element is Water, then the description reflects Water qualities
