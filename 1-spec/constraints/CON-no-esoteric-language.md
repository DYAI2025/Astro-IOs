# CON-no-esoteric-language: No Esoteric Language in User-Facing Text

**Category**: Operational

**Status**: Active

**Source stakeholder**: [STK-end-user](../stakeholders.md)

## Description

All user-facing text — Day Pulse/Trace, interpretations, quiz results, companion conversations — must avoid esoteric, astrological, or new-age jargon. The communication style is "poetic realism": atmospheric, sensory, grounded in everyday imagery. No "because Mercury is retrograde" — only "something feels different today."

## Rationale

The target audience explicitly does not identify with esoteric belief systems. They use astrology as a mental model for self-reflection, not as a truth claim. Esoteric language would alienate the core user base and undermine the mathematical transparency that differentiates Bazodiac.

## Impact

- Day Pulse/Trace text generator uses element-based atmosphere and natal archetype qualities, never planetary mechanics
- AI companions (Levi & Eve) must be prompted to avoid astro jargon in their system prompts
- Quiz result descriptions use personality psychology framing, not zodiac prophecies
- The word "because" followed by a planetary explanation is explicitly forbidden in user-facing text
- Internal data models and developer-facing code may use standard astrological terminology
