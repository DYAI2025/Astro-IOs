# CON-solo-founder: Single Founder Operation

**Category**: Business

**Status**: Active

**Source stakeholder**: [STK-product-owner](../stakeholders.md)

## Description

The project is built and operated by a single founder. There is no dedicated team — AI agents (Claude Code) perform the bulk of implementation while the human supervises, steers direction, and makes product decisions.

## Rationale

Bootstrap startup. No external funding at this stage. AI-first development model enables solo operation at a quality level that would traditionally require a small team.

## Impact

- All processes must be automatable or AI-executable
- No code review by other humans — AI agents review and validate
- Scope must be tightly managed to avoid overextension
- Infrastructure must be low-maintenance (managed services, not self-hosted)
- Documentation must be comprehensive enough for AI agents to operate autonomously
